# v0.3 independent review handoff

Status: **Independent security and specification review completed. Findings are reconciled in [the v0.3 review disposition](v0.3-review-disposition.md).**

## Implemented scope

- Register-all/activate-some Pi lifecycle with strict eager/lazy registry policy
- One shared `cli_tools` tool for deterministic metadata search and exact additive enable
- Ownership/collision/filtering checks, idempotent/concurrent enable behavior, and loader fallback
- Registered-versus-active diagnostics, compact rendering, and reload reset semantics
- Strict structured official sources for bundled GitHub CLI and ripgrep
- Backward-compatible local `cli_docs` calls plus explicit local/official operations
- Agent-independent hardened DNS/address/TLS/HTTPS/redirect transport
- Public-address-only CIDR policy, address pinning, TLS hostname verification, identity encoding, and fixed request headers
- Bounded UTF-8 textual response handling and event-based HTML text extraction
- Separate success-only session LRU, identical-flight deduplication, waiter cancellation, and awaited shutdown
- Deterministic bounded lexical excerpts, sanitization, untrusted framing, provenance, digests, and alignment
- Version-only installed evidence for supported fixed exact/version-match policies with factual match states
- Controlled unit, adapter, real Pi, package, and network-deny smoke coverage
- README, SECURITY, canonical design/roadmap, package manifest checks, and ADRs 0004/0005

## Explicitly excluded

- Arbitrary browsing or model-selected URLs
- Persistent/negative caches, crawling, link following, embeddings, or vector search
- Remote scripts, browser rendering, decompression, cookies, authentication, proxies, or custom trust roots
- Autonomous URL discovery or query interpolation
- Rich CLI-specific execution schemas or another agent adapter
- In-place unregistration/watching or native Windows execution
- Claims that official text is safe, current, or free of prompt injection
- Claims that generic CLI execution is sandboxed

## Independent review checklist

1. Confirm factory loading, discovery, startup, catalog search/enable, diagnostics, reload, and local-only documentation perform no remote network work.
2. Confirm every eligible lazy native tool is registered in Pi's full registry but removed initially only while adapter-owned.
3. Confirm enable rejects mixed-invalid batches before mutation, unions Pi's latest active names once, preserves unrelated tools, verifies ownership/postcondition, and never rolls back to a stale snapshot.
4. Confirm shared/native collisions and late ownership changes are visible and cannot be intentionally overridden.
5. Confirm reload/session replacement resets dynamic enables and both caches after awaited draining cleanup.
6. Confirm official source schema rejects legacy scalars, HTTP, userinfo, query/fragment, IP literals, Unicode/wildcards/trailing dots, non-443 ports, unknown fields, duplicate IDs, and unauthorized host/path changes.
7. Confirm model input cannot select any network authority or control and query/version values are not sent remotely.
8. Confirm every redirect repeats URL/host/path/DNS/address/TLS policy and all DNS answers are rejected if any is special.
9. Confirm the production connector pins the vetted address, keeps SNI/hostname verification, and verifies the peer before HTTP bytes can be released.
10. Confirm fixed headers omit auth/cookies/referrer/proxy data and identity-only response policy rejects compression.
11. Confirm every status, header, content-length, media, charset, UTF-8, body, timeout, cancellation, truncation, and network failure remains structured and uncached.
12. Confirm cache keys cover complete source/definition/version policy, values cross immutable clone boundaries, concurrent queries share fetched documents, and draining flights retain concurrency accounting.
13. Confirm HTML active content is ignored, controls are sanitized, excerpts are deterministic/bounded, and model text labels remote material untrusted.
14. Confirm alignment never upgrades latest/unknown/ambiguous evidence and fixed comparisons require configured version parsing.
15. Confirm Pi details/TUI/middleware stay bounded, serializable, and consistent with final `isError`.
16. Confirm the packed production manifest includes every new runtime module and parser dependency.
17. Confirm the real Pi smoke uses controlled executables, valid remote metadata, catalog search/enable, and a direct-network deny guard without public DNS, public HTTP, auth, or host CLI assumptions.

## Required review verification

```bash
npm run check
npm run security:audit
npm run smoke:pi
```

The delivery owner reruns these gates after disposition and records exact local and CI evidence in the pull request.
